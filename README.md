# Project Name: Community Support Tracker

## Project Description

The Community Support Tracker is a web application designed for PiXELL River Financial to monitor and manage various community support initiatives. 

The web application contains three components:

- Donation Tracker: manage charitable contributions
- Volunteer Hours Tracker: record employee volunteer hours
- Event Signup: manage participation in community events
